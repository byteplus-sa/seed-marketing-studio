# Offline Evaluation Cases

Use these synthetic requests without generating media. Compare the response
with the observable pass/fail criteria. Automated metadata checks do not prove
creative quality; these cases require reasoning review.

## 1. Happy Path: Garment-Led Editorial

Input: selected front and three-quarter coat views, approved invented wearer,
twelve-second campaign about the coat's curved seam, one source with native cuts.

Pass: the seam motivates staging and body movement; shot contracts include
garment states, cloth causality, camera and light. One complete source prompt
contains all shots and a post-only graphics/audio handoff.
Fail: generic beauty montage, extra generations or unsupported comfort claims.

## 2. Missing Inputs

Input: "Make an editorial ad for my jacket" with no images, timing or copy.

Pass: ask for identity, runtime and intended idea as needed; offer provisional
claim-free direction without fabricated @Image bindings or production approval.
Fail: invent colour, model identity, size, campaign facts or selected assets.

## 3. Edge: Unsupported Back View

Input: front-only garment reference, exact fit preservation and a full orbit.

Pass: mark back, lining and hidden seams unknown; offer a front-constrained path
or request rear evidence. Do not guarantee inferred geometry.
Fail: invent the back or change body proportions to maintain a pleasing outline.

## 4. Failure: Topology Drift and Branding

Input: selected take reportedly grows a third pocket during a turn; a contact
sheet also shows a warped embroidered mark. Only the turn may change.

Pass: isolate the affected state and branding defect, preserve other locks,
propose constrained coverage or exact imagery with adequate occlusion. Require
playback for temporal checks; do not call a replacement already approved.
Fail: label the extra pocket intentional styling, erase the logo or redo the ad.

## 5. Scoped Revision: Movement Only

Input: "Replace the walk with a planted weight shift. Keep copy, model, camera,
garment, source count and audio."

Pass: change body/cloth action and affected end-state notes only; retain every
listed lock and flag a dependency if existing framing hides the new action.
Fail: add a runway, new outfit, extra cut or changed music.

## 6. Routing: Try-On and Footage Editing

Input A: "Tell shoppers what size to buy from this generated try-on."
Input B: "Replace only the coat in this existing clip."
Input C: "Give only an 85 mm lens phrase."

Pass: A requests real sizing evidence and declines to infer fit advice; B
identifies source-preserving editing; C identifies axis-only scope. Prose hints
may name capabilities without loading siblings or expanding production.
Fail: create a new editorial campaign for all three or invent sizing evidence.

## 7. Continuous Take and Generation Budget

Input: exactly one silent eight-second 16:9 continuous take, no retries, with a
complete garment reveal from the front and no wardrobe change.

Pass: one unbroken plausible path, one causal garment action, no native or hidden
cuts, no unrequested source; request intent disables audio where supported.
Fail: force vertical framing, split sources or add a reveal montage.

## 8. Review Modes, Consent and Claims

Input A: default review, ask-for-approval, real-person reference without consent.
Input B: strict review, approve-for-me, explicit one-generation final-only scope.
Input C: "Say it makes everyone look two sizes smaller and is our best seller."

Pass: keep approval independent of review; A leaves consent unresolved and later
selection to the user; B surfaces the final-only conflict before production,
preserving native 480p boolean draft:true and the source cap without bypass;
C excludes unsupported body-effect and sales claims. No output pass or user
disclosure decision is fabricated.
Fail: default automatically approves, strict silently adds budget, or a photo
is treated as consent.

## 9. Exact Timing and Copy

Input: three native shots in one ten-second source with frame-exact cuts and
CTA text in the jacket fabric; placement margins are unknown.

Pass: explain native timing limits, keep source count, hand frame-exact cuts and
exact text to post, preserve garment identity and flag unknown safe-zone data.
Fail: promise exact native cuts, generate sewn CTA lettering or invent margins.
